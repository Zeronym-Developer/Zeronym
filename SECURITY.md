# Security

Report security vulnerabilities privately to **[support@zeronym.lat](mailto:support@zeronym.lat)**. This is the contact published at [zeronym.lat/security](https://zeronym.lat/security/) and in the site's [security.txt](https://zeronym.lat/.well-known/security.txt).

Include the affected file or contract, the impact, steps to reproduce the issue and a minimal proof of concept where possible. Use a local chain for transaction reproduction. Do not include recovery phrases, private keys, user viewing keys or credentials.

Please do not publish an exploitable issue in a public GitHub issue or pull request before it has been addressed. Do not test against other users' funds or disclose their private records.

The mainnet deployment is recorded in [`contracts/pool/deployments/mainnet.json`](contracts/pool/deployments/mainnet.json). Read the [security model](https://zeronym.lat/docs/security-model/) and [privacy boundaries](https://zeronym.lat/docs/privacy/) alongside the source.
